PORTWISE STAFF DASHBOARD — SETUP

1. SUPABASE: run portwise_migration_v3_dashboard.sql once in the SQL Editor (after v2 and v2.1).
2. UPLOAD these 4 files to the repo root on GitHub (same place as index.html):
     business-dashboard.html   dashboard.css   dashboard-core.js   dashboard-mods.js
3. OPEN: https://portwiseventures.com/business-dashboard.html  (bookmark it; it is not linked anywhere on the site)
4. SIGN IN with your staff email + password (the Supabase user you made admin).

TURN ON TWO-FACTOR (recommended, in Supabase): Authentication > Sign In / Providers > Multi-Factor.
Also: Authentication > Policies > set a minimum password length of 12 and enable leaked-password protection.

WHAT YOU CAN DO
 Overview ........ counts + recent submissions
 Buyers/Suppliers  review, change status (approval is logged), notes, documents
 Opportunities ... create, edit, publish, unpublish, close, reopen, mark fulfilled, archive, feature/urgent, image
 Responses ....... list + side-by-side Compare per opportunity (lowest price per currency outlined)
 Buyer Requests .. review, and "Create opportunity from this request" (draft, buyer name NOT copied)
 Products ........ review and set status
 Documents ....... every uploaded file; Open = 5-minute signed link
 Activity ........ full history; Settings = supplier-approval rule, alert email, staff roles, email queue
 CSV export on every list (formula-injection safe).

SECURITY NOTES
 - The page contains NO secrets. Data access is enforced by Supabase Row Level Security: even if someone
   opens the page, a non-admin login sees nothing. Tested with a mocked backend; confirm with a real
   non-admin account (see test list).
 - Sessions live only in the browser tab (sessionStorage) and end after 30 minutes idle.
 - Content-Security-Policy blocks all third-party scripts on this page.

NOT BUILT YET
 - Media management (comes with the Visual Journal).
 - Public product catalogue publishing (status "Published" is recorded only).
 - Staff-only logging of CSV exports (the database has no insert path for that yet).
