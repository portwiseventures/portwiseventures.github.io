HS codes explained: why classification decides your duty and paperwork

The Harmonized System is the international product code used by customs worldwide. The code you declare affects the duty rate, import rules and statistics for your shipment.

What the Harmonized System is

The Harmonized Commodity Description and Coding System, usually called the HS, is an international product nomenclature developed by the World Customs Organization (WCO). Almost every country bases its customs tariff and trade statistics on it.

How a code is built

The first six digits are the same in every country that uses the HS. Most countries add further digits for their own national tariff, so a full import code is commonly eight or ten digits and differs by destination.

Why it matters to buyers and exporters

  • It determines the duty rate and whether a trade agreement preference applies.
  • It decides which import requirements apply, such as licences, certificates or inspections.
  • It appears on invoices, customs declarations and statistics, so inconsistent codes cause delays.

Editions and updates

The HS is revised about every five or six years. HS 2022 is the edition currently in force. The next edition, HS 2028, was announced by the WCO in January 2026 and is due to enter into force on 1 January 2028. Countries then adapt their national tariffs, so check your destination's schedule when it approaches.

Good practice

  • Describe the product by what it is made of, how it is processed and what it is used for, then classify with the destination country's tariff.
  • Ask your supplier or customs broker which code they use, and confirm it matches the importer's.
  • Where available, ask the customs authority for an advance ruling if a code is uncertain.
  • Use the same code on every document for the shipment.
